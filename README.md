# HR Analytical Dashboard

## Project Overview
This Data Analytics project was developed using Microsoft Power BI to analyze workforce data and uncover meaningful HR insights through interactive and dynamic visualizations.

## Key Highlights
- Employee & Active Workforce Analysis
- Attrition Rate & Employee Retention Tracking
- Department-wise Employee Distribution
- Salary Slab Attrition Analysis
- Age Group Insights
- Experience-based Attrition Trends

## Tools & Skills Used
- Microsoft Power BI
- Data Cleaning
- Data Modeling
- DAX
- Data Visualization
- Dashboard Design

## Insights Generated
- Identified departments with higher employee attrition
- Analyzed workforce distribution across age groups
- Evaluated attrition trends based on experience levels
- Explored salary-wise employee movement patterns
- Built interactive filters for deeper business insights

## Outcome
This project helped strengthen my skills in Business Intelligence, dashboard development, and transforming raw data into actionable insights.
